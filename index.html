The robot is placed in a random position and heading, so there is no route to plan. Choose the sensors you attach, check how the strategy behaves on a scale drawing of the course, and get MicroPython for a Raspberry Pi Pico 2 W with a Kitronik 5331 motor driver and your WNE103.py motor functions.

Mode:

The robot runs these steps in order. It only works if it is placed at the planned start position and heading, so use it for practice, not for a random start.

    Robot and sensors

    On the day the robot is placed anywhere in the Start zone (x = 0 to 12 in) at any heading. The preview shows one start at a time, and the test button tries 24 random ones. Both tracks are on the same floor, so one robot uses one track.

    Attach sensors

    The robot faces right. Choose a sensor below, then click an edge of the rectangle to place it, or type the side and offset. Offset is measured from the middle of that edge.

    Sharp GP2Y0A21YK0F: analog output to an ADC pin (GP26, 27 or 28), 5 V supply, reads about 4 to 31 in. Switch (MS0850502F01S1A): the lever sits at about 30° to the surface, and you can extend it to wrap around the wheel so one switch covers a whole side. Common to GND, normally-open contact to a GP pin with the Pico pull-up, so pressed reads 0. A Sharp set to "Down at the floor" must be mounted at least 4 in above the floor: it reads that height on the track and a much larger value past the edge. A Sharp avoids a wall; a switch finds it by touching it.

    Calibration
    These numbers are starting guesses. Generate calibrate.py below, run it on your robot, measure, and type your results here.

    TT motors usually stall below about 30 % duty. Speeds scale linearly in the preview, which is only an approximation, so re-measure if you change speeds a lot.

    Motors, LED and start trigger

    Defaults match KitronikPicoMotor() in WNE103.py, which then needs no pin arguments. If the robot drives backwards, tick Reverse. If it turns the wrong way, swap the left motor port.

    Scoring estimate

    Defaults follow the DP2 rules: 50 points up to 30 s, then 50·exp(−0.008·(t − 30)). The instructors may change this, so edit the numbers if they do.
